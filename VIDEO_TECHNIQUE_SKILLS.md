# Curated Video Technique Skills

This catalogue adds **12 focused techniques** to the existing AI Simplified Lab video-factory skills. The 10 Lemo-Opuscar adaptations are selected for this channel's faceless AI explainers, product tutorials and evidence-led AI news. Two additional skills add cross-cutting direction and brand-mark motion.

These are **technique modules, not mandatory templates**. The agent must choose only the technique that helps the current story. Existing project style DNA, user-approved style rules, rights gates, QA gates and composition layouts take precedence.

## Selection rules

1. Read the existing project style and its user-approved preferences before selecting a technique.
2. Select one primary technique for a scene or short sequence. Add a secondary technique only when it serves a clearly different purpose.
3. Do not apply all techniques to every video. Avoid mixing multiple visual grammars in one scene without a narrative reason.
4. Preserve AI Simplified Lab's faceless preference, simple international English, vertical 1080x1920 / 30fps output, purple-collage brand where applicable, verified asset rights and fail-closed release gate.
5. Preserve current project identities, including ELI5 Whiteboard Dialogue and Technical Notebook Explainer. A technique skill must adapt to an existing style; it must not silently replace it.
6. Prefer HyperFrames, HTML/CSS/SVG and GSAP already in the repository. Do not add paid APIs, external CDNs, Remotion, heavy 3D, new Python environments or model services for these techniques.
7. Keep compositions deterministic: animation state must be a function of timeline/frame time; seed any randomness; direct frame seeking must match sequential rendering.
8. Always validate the final MP4, not only source code or preview images. Use existing caption, media, rights, visual-diversity and release checks.

New technique modules are additive. They do not replace or rewrite those existing skills.
