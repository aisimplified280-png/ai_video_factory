CORE PRINCIPLE

Smarter Context Design

ARCHITECTURAL RULE

Place static instructions at the top and dynamic queries at the bottom to maximize warm cache hits.

Reference: Anthropic Prompt Caching Documentation
If you are building with Claude, re-sending entire documents on every prompt wastes substantial bandwidth.
Prompt caching stores your system instructions in memory, allowing subsequent calls to read directly from cache.
Simply add the ephemeral cache control block to your system prompt to activate instant prefix matching.
Structure your static context at the start of the prompt to maximize warm cache hits and minimize latency.
