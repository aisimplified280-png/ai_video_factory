# Cross-Topic Visual Benchmark

Use a fixed benchmark set covering:
AI agents, robotics, biotech, cybersecurity, finance, cloud infrastructure, databases, quantum computing.

For each topic render comparable-length test videos.

Compare actual scene frames on:
- semantic subject
- environment
- composition geometry
- focal location
- major primitives
- camera behavior
- motion trajectory
- character interaction
- transition style
- depth structure

Do not score only color or text changes.

Generate a matrix showing pairwise structural similarity.

Fail when unrelated topics repeatedly converge on one visual template.

The benchmark is a regression suite for the entire creative engine.
