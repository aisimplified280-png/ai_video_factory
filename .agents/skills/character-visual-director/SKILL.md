# Character Visual Director

Characters are fictional visual storytellers, not presenters.

Required scene contract:
- character_id
- character_role
- character_action
- interaction_target
- emotion/reaction
- depth_layer
- placement
- scale
- camera_relationship
- continuity notes

Planning chain:
narration → subject → visual_purpose → visual_metaphor → character_role → character_action → interaction_target

Examples:
- robotics: engineer-bot inspecting a gripper, loading a component, or monitoring a workcell
- AI/software: lab-bot connecting model/tool nodes or inspecting an agent task
- cybersecurity: detective-bot tracking an intrusion path
- biotech: lab-bot examining DNA/protein structures
- finance: analyst-bot inspecting a market event
- cloud: infrastructure-bot moving between servers/services

Rules:
- never use real-person likenesses
- never use talking-head framing
- never stand idle as decoration
- usually occupy 10–30% of meaningful scene area
- never cover captions or the primary subject
- vary pose, action, location, scale, and camera relationship across scenes
- preserve mascot identity while adapting props and environment to the domain

The director must be able to explain why the character exists in each scene.
