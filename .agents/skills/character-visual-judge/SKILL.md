# Character Visual Judge

For every character scene inspect actual frames and determine:
- is the character visibly present?
- is the character role understandable?
- is it interacting with the intended subject?
- is the action visible?
- is the pose distinct from neighboring scenes?
- is the character secondary to the topic?
- is it clear of captions and CTA?
- does it look like the same fictional mascot where continuity is intended?

Reject:
- idle mascot
- mascot pasted over generic background
- repeated pose/location
- character replacing the technical subject
- action claimed in metadata but not visible in pixels
