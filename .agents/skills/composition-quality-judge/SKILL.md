# Composition Quality Judge

Inspect actual rendered frames.

Judge:
- focal-point clarity
- subject scale
- visual hierarchy
- balance/asymmetry
- whitespace
- edge collisions
- caption/CTA clearance
- text readability
- mobile readability
- subject obstruction
- clutter
- repetitive card/grid framing

Score the composition independently of scene metadata.

A visually correct subject can still fail because the composition is weak or unreadable.
